# RiftStrike — Entrega Compacta

Projeto Three.js/Vite do remix FPS Iron Rift, compactado para ficar abaixo de 30 MB.

## Executar

```bash
pnpm install
pnpm dev
```

## Build de produção

```bash
pnpm build
```

Esta versão mantém código, assets integrados, configuração do leaderboard, metadata de compartilhamento e favicon. Para atingir o limite, a documentação visual de referência foi removida da entrega e a capa OG foi redimensionada de 2560×1440 para 1200×675 sem alterar sua proporção.
